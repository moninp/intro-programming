MATH 5200: Computing Using R & Python

Fall 2026

This is the course website and source repository for MATH 5200: Computing Using R & Python.

The course provides a fast-paced introduction to Python and R for graduate study in mathematics and statistics. In addition to programming fundamentals, we will study computational thinking, numerical computing, data management, testing and debugging, version control, reproducibility, and other practices used in professional computational work.

ImportantStart Here

If you are new to the course, begin with Getting Started.

It contains instructions for:

  • installing the required software;
  • setting up Python and the course virtual environment;
  • configuring VS Code;
  • obtaining and updating the course repository; and
  • running the course’s Quarto examples.

Software and Tools

The course uses:

  • Python 3
  • R
  • Visual Studio Code
  • Quarto
  • Git
  • GitHub

You do not need to be an expert with any of these tools at the beginning of the course. We will learn the relevant parts as we go.

The course repository itself is part of the course. You will use Git and GitHub to obtain course materials and will learn how version control fits into a reproducible computational workflow.

Getting Help

If you encounter a problem with the software or course materials, please consult Getting Started.

If you still cannot resolve the problem, please contact the instructor or bring the problem to class or office hours.

When asking for help with programming, it is particularly useful to provide:

  1. the code you ran;
  2. the error message or unexpected result;
  3. what you expected to happen; and
  4. what you have already tried.

Learning to describe a computational problem clearly is itself an important programming skill.
