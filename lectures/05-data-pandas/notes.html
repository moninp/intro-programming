Lecture 5 — Data Analysis with Pandas

Background Notes

1. Introduction

Data analysis in Python centers on the pandas library, which provides high-performance, easy-to-use data structures and analysis tools. This lecture uses Chicago’s Divvy bike-share system as a case study to demonstrate how pandas transforms raw data into analytical insights.

The Divvy dataset is pedagogically valuable because it exhibits real-world data characteristics:

  • Large scale: May 2024 contains approximately 609,000 trip records
  • Structured missingness: Station information is systematically missing for dockless bikes
  • Temporal complexity: Datetime parsing and feature extraction
  • Categorical variables: Bike types, rider types, stations
  • Analytical questions: Usage patterns, temporal trends, user segmentation

Throughout these notes, we focus on the central question: How do members and casual riders use Chicago’s bike-share system differently? This question motivates data loading, cleaning, transformation, aggregation, and visualization operations.

The notes are organized to match the lecture progression but include additional depth on pandas internals, edge cases, and best practices. Code examples use a sample dataset that can be created inline, ensuring all code executes without external dependencies.

3.2 Row Selection with loc and iloc

Pandas provides two primary indexers for row selection:

  • loc: Label-based indexing
  • iloc: Integer position-based indexing
# iloc: integer position
print("First 3 rows using iloc:")
print(df_original.iloc[0:3][['ride_id', 'rideable_type', 'member_casual']])

# loc: label-based (here using default integer index)
print("\nRows 0-2 using loc:")
print(df_original.loc[0:2, ['ride_id', 'rideable_type', 'member_casual']])

# Difference: iloc excludes end, loc includes end with integer labels
print("\nNote: iloc[0:3] gets 3 rows, loc[0:2] gets 3 rows (0, 1, 2)")

14. Performance Optimization

14.1 Vectorization

Always prefer vectorized operations over loops:

import time

# Create larger sample
large_sample = pd.DataFrame({
    'value': np.random.randn(10000)
})

# Bad: loop
start = time.time()
result_loop = []
for val in large_sample['value']:
    result_loop.append(val ** 2)
loop_time = time.time() - start

# Good: vectorized
start = time.time()
result_vectorized = large_sample['value'] ** 2
vectorized_time = time.time() - start

print(f"Loop time: {loop_time:.4f} seconds")
print(f"Vectorized time: {vectorized_time:.4f} seconds")
Loop time: 0.0025 seconds
Vectorized time: 0.0002 seconds

14.2 Efficient Data Types

# Optimize numeric types
df_optimized = df_original.copy()

# Downcast integers
for col in df_optimized.select_dtypes(include=['int64']).columns:
    df_optimized[col] = pd.to_numeric(df_optimized[col], downcast='integer')

# Downcast floats
for col in df_optimized.select_dtypes(include=['float64']).columns:
    df_optimized[col] = pd.to_numeric(df_optimized[col], downcast='float')

# Convert to category

18. Key Takeaways

  1. Pandas DataFrames are two-dimensional labeled data structures with columns of potentially different types, analogous to spreadsheets or SQL tables.

  2. Series are one-dimensional labeled arrays that form the columns of DataFrames and support vectorized operations.

  3. loc and iloc provide label-based and position-based indexing respectively; loc includes the endpoint in slices while iloc follows Python’s standard slicing behavior.

  4. Boolean indexing enables powerful filtering using conditions; combine multiple conditions with & (and), | (or), and ~ (not).

  5. Missing data should be understood before being handled; the Divvy dataset demonstrates that missingness patterns can be meaningful rather than random.

  6. Data type conversion improves performance and correctness; categorical types significantly reduce memory usage for columns with repeated values.

  7. DateTime operations require converting string columns to datetime types using pd.to_datetime(), enabling temporal analysis through the dt accessor.

  8. Derived variables extend datasets with calculated columns, temporal features, categorical binning, and conditional logic.

  9. GroupBy operations implement split-apply-combine patterns, allowing aggregation, transformation, and filtering at group levels.

  10. Pivot tables reshape data for multi-dimensional analysis, creating cross-tabulations with flexible aggregation functions.

  11. Merging and joining combine datasets similar to SQL joins; understand the differences between inner, left, right, and outer joins.

  12. Vectorized operations are orders of magnitude faster than Python loops; always prefer pandas/NumPy operations over iteration.

  13. Memory optimization through appropriate data types (categorical, downcasting) enables analysis of larger datasets.

  14. Data validation checks for range violations, consistency issues, and outliers before analysis to ensure data quality.

  15. Chaining operations creates readable analysis pipelines but consider assigning intermediate results for debugging.

  16. Categorical data benefits from the category dtype for memory efficiency and ordered operations.

  17. Query method provides SQL-like filtering syntax that can be more readable for complex conditions.

  18. Rolling and window functions enable moving averages, cumulative statistics, and time-series analysis.
