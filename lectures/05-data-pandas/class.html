Lecture 5: Data, Files, and the Path from Raw Information to Analysis

From raw hurricane observations to scientific insight

Central Question

How does raw information become a dataset that can support analysis?

Imagine you’re a meteorologist studying Atlantic hurricanes. The National Oceanic and Atmospheric Administration (NOAA) has collected over 170 years of hurricane observations—positions, wind speeds, pressures, and storm classifications. This raw data sits in text files with cryptic codes, missing values, inconsistent formats, and timestamps that span three different centuries of data collection practices.

Your goal: determine whether hurricanes are becoming more intense, identify the deadliest storms in history, and find geographic patterns in storm tracks. But first, you must transform these raw observations into a structured dataset suitable for analysis. This is not a simple matter of “loading the data”—it requires understanding file formats, inspecting data quality, handling missing values, creating derived variables, merging information from multiple sources, and validating your transformations.

Today, we’ll follow the complete journey from raw hurricane data files to analysis-ready datasets. You’ll learn to read various file formats, use pandas DataFrames effectively, identify and fix data quality issues, group and aggregate observations, merge datasets, and produce initial visualizations. By the end of class, you’ll understand that data management isn’t just technical bookkeeping—it’s an essential part of scientific reasoning where decisions about data shape the conclusions you can draw.

NoteCommon Data Quality Issues
  1. Missing values: Represented as NaN, None, empty strings, or special codes
  2. Wrong data types: Numbers stored as strings, dates as text
  3. Invalid values: Impossible measurements (negative wind speeds, dates in future)
  4. Duplicates: Same observation recorded multiple times
  5. Inconsistent units: Mixing mph and km/h, Fahrenheit and Celsius
  6. Inconsistent categories: “Category 5”, “Cat5”, “5”, “five” all meaning the same thing

Exercise 2.2: Handling Missing Data

Missing data is common in historical records. We need to decide: drop it, fill it, or flag it?

Just-in-Time Concept: Missing Data Strategies

import pandas as pd
import numpy as np

# Create example data with missing values
data = {
    'storm': ['AL01', 'AL02', 'AL03', 'AL04', 'AL05'],
    'wind': [80, np.nan, 120, 95, np.nan],
    'pressure': [990, 985, np.nan, 992, 988]
}
df = pd.DataFrame(data)

print("Original data:")
print(df)

# Strategy 1: Drop rows with ANY missing values
df_dropped = df.dropna()
print("\nDrop any missing:")
print(df_dropped)

# Strategy 2: Drop rows missing SPECIFIC columns
df_dropped_wind = df.dropna(subset=['wind'])
print("\nDrop missing wind only:")
print(df_dropped_wind)

# Strategy 3: Fill with a value
df_filled = df.fillna(0)
print("\nFill with 0:")
print(df_filled)

# Strategy 4: Forward fill (use previous value)
df_ffill = df.ffill()
print("\nForward fill:")
print(df_ffill)

# Strategy 5: Fill with column mean
df['wind_filled'] = df['wind'].fillna(df['wind'].mean())
print("\nFill with mean:")
print(df)

    """Calculate distance traveled by storm"""
    group = group.sort_values('date')
    lat_diff = group['lat'].diff()
    lon_diff = group['lon'].diff()

print(merged_left)

# Outer merge: keep all storms from both
merged_outer = pd.merge(tracks, damage, on='storm_id', how='outer')

Challenge: Synthesis

Returning to the Central Question

We started by asking: How does raw information become a dataset that can support analysis?

You’ve now experienced the complete workflow:

  1. Files and formats: Read CSV and JSON data from URLs and local files
  2. Initial inspection: Examine shape, columns, types, and summary statistics
  3. Data quality: Identify missing values, wrong types, and invalid entries
  4. Cleaning: Handle missing data, convert types, validate values
  5. Transformation: Create derived variables, extract date components, categorize
  6. Persistence: Save cleaned data for future use
  7. Grouping: Aggregate by categories to find patterns
  8. Merging: Combine data from multiple sources
  9. Visualization: Create plots to see patterns
  10. Discovery: Find unexpected features in the data

Looking Beyond

Today we worked with a single data file that was already mostly structured. Real projects often involve:

  • Multiple data sources that must be aligned
  • Inconsistent formats and schemas
  • Larger datasets requiring different tools
  • Streaming data that arrives continuously
  • Missing documentation about what variables mean
  • Legacy systems with cryptic codes

The principles you learned today—inspect, validate, transform, document—apply regardless of scale.
