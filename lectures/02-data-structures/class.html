2. Text Encoding

Computers ultimately store information as bits. In Lecture 1, we saw how integers and floating-point numbers can be represented using binary.

But what about text?

Consider the string:

message = "Hello"

A computer cannot directly store the abstract idea of the letter H. It needs a numerical representation.

This leads to three related concepts:

  1. characters - symbols such as A, é, or 中;
  2. code points - numerical identifiers assigned to characters by a character encoding standard;
  3. bytes - groups of eight bits used to represent stored data.

ASCII

The earliest widely used character encoding schemes included ASCII, the American Standard Code for Information Interchange.

ASCII assigns numbers to a relatively small collection of characters:

ord("A")
65
ord("a")
97
ord("0")
48

The inverse operation is chr():

chr(65)
'A'
chr(97)
'a'

ASCII is useful, but it has an important limitation: it contains only a small number of characters.

It can represent English letters, digits, punctuation, and various control characters, but it cannot represent the world’s writing systems.

Unicode

Unicode is a much larger system designed to assign code points to characters from languages and writing systems around the world.

For example:

ord("A")
65
ord("é")
233
ord("中")
20013

Notice that a Unicode code point is just an integer.

We can convert it back to a character:

chr(233)
'é'
chr(20013)
'中'
Important

A character’s Unicode code point is not necessarily the same thing as the sequence of bytes used to store that character.

This distinction becomes important when we work with files and data from different sources.

UTF-8

Unicode tells us which numerical code point corresponds to a character. We still need a way to represent that information as bytes.

UTF-8 is a widely used encoding for doing this.

Python allows us to encode a string into bytes:

text = "Hello"
encoded = text.encode("utf-8")

encoded
b'Hello'

We can inspect the individual bytes:

list(encoded)
[72, 101, 108, 108, 111]

Now consider a string containing a non-ASCII character:

text = "café"
encoded = text.encode("utf-8")

encoded
b'caf\xc3\xa9'
list(encoded)
[99, 97, 102, 195, 169]

The character é is one character, but its UTF-8 representation requires multiple bytes.

We can convert the bytes back into a string using .decode():

encoded.decode("utf-8")
'café'

The general process is:

character
    ↓
Unicode code point
    ↓
UTF-8 encoding
    ↓
bytes

and, in the other direction:

bytes
    ↓
UTF-8 decoding
    ↓
Unicode code point
    ↓
character

3. Strings

A Python string is a sequence of characters.

name = "Python"

We can determine its length:

len(name)
6

We can access individual characters using indexing:

name[0]
'P'
name[1]
'y'

Python uses zero-based indexing.

That means:

P  y  t  h  o  n
0  1  2  3  4  5

We can also index from the end:

name[-1]
'n'
name[-2]
'o'

Slicing

We can obtain a portion of a string using a slice:

name[0:3]
'Pyt'

The general form is:

sequence[start:stop]

The start position is included, while the stop position is excluded.

For example:

name[1:4]
'yth'

We can also omit either endpoint:

name[:3]
'Pyt'
name[3:]
'hon'

And we can use a step:

name[::2]
'Pto'
name[::-1]
'nohtyP'

Strings Are Immutable

An important property of Python strings is that they are immutable.

For example, this does not work:

name[0] = "p"

Instead, operations that appear to modify a string actually create a new string.

name = "Python"

lower_name = name.lower()

name, lower_name
('Python', 'python')

The original string has not changed:

name
'Python'

String Methods

Python provides many useful string methods.

text = "  Hello, World!  "
text.strip()
'Hello, World!'
text.lower()
'  hello, world!  '
text.upper()
'  HELLO, WORLD!  '
text.replace("World", "Python")
'  Hello, Python!  '
text.split(",")
['  Hello', ' World!  ']

We can also test properties of strings:

"12345".isdigit()
True
"Hello".isalpha()
True
"hello".startswith("he")
True
"hello".endswith("lo")
True

4. Data Structures

So far we have worked mostly with individual values and strings.

Real computational problems usually require us to work with collections of values.

Python provides several fundamental data structures for this purpose:

  • lists;
  • tuples;
  • dictionaries;
  • sets.

The choice of data structure is not merely a matter of style. It should reflect the operations we need to perform.

Lists

A list is an ordered, mutable collection.

numbers = [10, 20, 30, 40, 50]

We can index a list:

numbers[0]
10

and slice it:

numbers[1:4]
[20, 30, 40]

We can change an element:

numbers[0] = 99

numbers
[99, 20, 30, 40, 50]

We can append an element:

numbers.append(60)

numbers
[99, 20, 30, 40, 50, 60]

We can remove an element:

numbers.remove(30)

numbers
[99, 20, 40, 50, 60]

Lists can contain different types of objects:

example = [1, "hello", 3.14, True]

But in practice, a list will often contain objects of the same general type.

Tuples

A tuple is an ordered, immutable sequence.

point = (3, 4)

We can access its elements:

point[0]
3

But we cannot change them:

point[0] = 5

The distinction between lists and tuples is therefore partly about whether the collection should be mutable.

Note

Do not memorize a rule such as “always use a list” or “always use a tuple.”

Instead, ask what your data represent and what operations your program needs to perform.

Dictionaries

A dictionary stores key-value pairs.

student = {
    "name": "Alice",
    "age": 24,
    "program": "Mathematics"
}

We can retrieve a value using its key:

student["name"]
'Alice'
student["age"]
24

We can add or change entries:

student["year"] = 1

student
{'name': 'Alice', 'age': 24, 'program': 'Mathematics', 'year': 1}

Dictionaries are particularly useful when we want to associate one piece of information with another.

For example:

student ID → student name
country → population
word → frequency
stock ticker → price

This is why a dictionary is a natural choice for our character-frequency problem.

Character Frequency with a Dictionary

Consider:

text = "banana"

We want to construct:

b → 1
a → 3
n → 2

One way to describe the algorithm is:

  1. Start with an empty dictionary.
  2. Examine each character.
  3. If the character has not appeared before, initialize its count to zero.
  4. Increase its count by one.
  5. Continue until all characters have been processed.

Let’s implement this directly.

text = "banana"

counts = {}

for character in text:
    if character not in counts:
        counts[character] = 0

    counts[character] += 1

counts
{'b': 1, 'a': 3, 'n': 2}

Notice what we have done.

We have taken an informal problem—

“Count how frequently each character occurs.”

—and translated it into a precise sequence of computational steps.

That is algorithmic thinking.

Sets

A set is an unordered collection of unique elements.

numbers = {1, 2, 3, 2, 1}

numbers
{1, 2, 3}

Duplicates are automatically removed.

Sets are particularly useful when we care about membership or uniqueness, rather than ordering.

"A" in {"A", "B", "C"}
True

Sets also support mathematical set operations:

a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
a | b
{1, 2, 3, 4, 5, 6}
a & b
{3, 4}
a - b
{1, 2}

These correspond to union, intersection, and difference.

5. Control Flow

So far, Python has executed our statements sequentially.

But useful programs need to make decisions and repeat operations.

Control flow determines which statements a program executes and how many times it executes them.

The fundamental tools are:

  • conditional statements;
  • for loops;
  • while loops.

Conditional Statements

The basic structure is:

if condition:
    statement

For example:

x = 10

if x > 0:
    print("positive")
positive

We can add an alternative:

x = -3

if x > 0:
    print("positive")
else:
    print("not positive")
not positive

And multiple possibilities:

x = 0

if x > 0:
    print("positive")
elif x < 0:
    print("negative")
else:
    print("zero")
zero

Boolean Logic

Conditions evaluate to True or False.

x = 10

x > 0
True
x == 10
True
x != 5
True

We can combine conditions using and, or, and not.

x > 0 and x < 20
True
x < 0 or x > 100
False
not (x == 10)
False

for Loops

A for loop repeats an operation over the elements of a collection.

numbers = [10, 20, 30, 40]

for number in numbers:
    print(number)
10
20
30
40

The loop variable takes on each value in sequence.

We can perform computations inside the loop:

numbers = [10, 20, 30, 40]

for number in numbers:
    print(number ** 2)
100
400
900
1600

We can combine loops with conditionals:

numbers = [1, 2, 3, 4, 5, 6]

for number in numbers:
    if number % 2 == 0:
        print(number)
2
4
6

range()

The range() function is useful when we want to iterate over a sequence of integers.

for i in range(5):
    print(i)
0
1
2
3
4

Remember that the endpoint is excluded.

We can specify a starting point:

for i in range(2, 7):
    print(i)
2
3
4
5
6

And a step:

for i in range(0, 10, 2):
    print(i)

2
4
6

while Loops

A while loop repeats as long as a condition remains true.

x = 1

while x <= 5:
    print(x)
    x += 1
1
2
3
4
5

A while loop is useful when we do not know in advance exactly how many iterations will be required.

For example:

x = 1

while x < 100:
    x *= 2

x
128

Be careful: if the condition never becomes false, the loop will never terminate.

Warning

Infinite loops are a common programming error.

Whenever you write a while loop, ask:

What changes during each iteration that will eventually make the condition false?

6. List Comprehensions

Python provides a compact way to construct lists called a list comprehension.

Suppose we want the squares of the integers from 0 through 9.

A conventional loop is:

squares = []

for i in range(10):
    squares.append(i ** 2)

squares
[0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

A list comprehension expresses the same idea more compactly:

squares = [i ** 2 for i in range(10)]

squares
[0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

We can also include a condition.

For example, the squares of the even integers:

even_squares = [i ** 2 for i in range(10) if i % 2 == 0]

even_squares
[0, 4, 16, 36, 64]

List comprehensions are useful, but they should not be used merely to make code shorter.

Note

Readability matters.

A three-line loop that is immediately understandable is often preferable to a complicated one-line comprehension.

We will return repeatedly to the idea that good code should be easy for another person to understand.

7. Algorithmic Thinking

We have now encountered several examples where we started with a problem and translated it into computational steps.

That process is central to programming.

An algorithm is a precise procedure for solving a problem.

A useful conceptual workflow is:

Problem
   ↓
Specification
   ↓
Algorithm
   ↓
Implementation
   ↓
Testing
   ↓
Result

This is closely related to the computational workflow introduced in Lecture 1.

From Problem to Algorithm

Consider the problem:

Given a list of numbers, determine the largest value.

A natural algorithm is:

  1. Start with the first value as the current maximum.
  2. Examine the next value.
  3. If it is larger than the current maximum, make it the new maximum.
  4. Continue until every value has been examined.
  5. Return the maximum.

We can implement this directly:

numbers = [7, 3, 12, 5, 9]

current_max = numbers[0]

for number in numbers[1:]:
    if number > current_max:
        current_max = number

current_max
12

Python of course already provides:

max(numbers)
12

But implementing the algorithm ourselves is useful because it forces us to understand the underlying procedure.

A useful strategy for complicated computational problems is to break them into smaller problems.

For example, suppose we want to determine the average of all positive values in a list.

Rather than thinking:

Break it down:

  1. Identify the positive values.
  2. Add them together.
  3. Count them.
  4. Divide the sum by the count.

Each step is easier to implement and test independently.

8. A First Look at Computational Complexity

Two algorithms can produce the same answer while requiring very different amounts of computational work.

Suppose we have a list containing n observations.

A simple loop through the entire list requires work proportional to n.

We describe this informally as:

\[ O(n) \]

For example:

numbers = list(range(100))

total = 0

for number in numbers:
    total += number

total
4950

The loop processes each observation once.

Now consider a nested loop:

numbers = list(range(100))

count = 0

for x in numbers:
    for y in numbers:
        count += 1

count
10000

The inner loop runs once for every combination of x and y.

With n observations, this requires roughly:

\[ n^2 \]

operations, or:

\[ O(n^2). \]

For n = 100, this may not matter.

For n = 1,000,000, it matters enormously.

Important

You do not need to become a theoretical computer scientist to write good statistical or mathematical programs.

But you should develop the habit of asking:

How does the amount of work required by this algorithm grow as my data become larger?

Exercise: Compare Two Algorithms

Suppose we want to determine whether a particular value occurs in a list.

A straightforward approach is to examine the elements one at a time:

numbers = list(range(100))

found
True

Python also provides:

True

Now consider what happens if we need to perform this membership test thousands or millions of times.

Would a list always be the best data structure?

Think back to sets.

numbers_set = set(numbers)

True

This is an example of a broader principle:

The choice of algorithm and data structure can determine whether a computational problem is easy or difficult at scale.

10. Summary

Text and Encoding

  • Computers ultimately store information as bits and bytes.
  • Unicode assigns code points to characters.
  • UTF-8 provides a way to encode Unicode characters as bytes.
  • A character, a code point, and its byte representation are related but distinct concepts.

Data Structures

Python provides several fundamental ways to organize collections of information:

Data structure Key property Typical use
list Ordered, mutable Sequence of observations
tuple Ordered, immutable Fixed collection such as coordinates
dict Key-value mapping Associations and counts
set Unique elements Membership and uniqueness

The appropriate data structure depends on the operations your problem requires.

Control Flow

We used:

  • if / elif / else;
  • Boolean expressions;
  • for loops;
  • while loops;
  • range();
  • list comprehensions.

These allow programs to make decisions and repeat computations.

Algorithms

An algorithm is a precise procedure for solving a problem.

A useful workflow is:

Problem
→ specification
→ algorithm
→ implementation
→ testing
→ result

We also saw that different algorithms can require very different amounts of computational work.
