Lecture 4: Numerical Computing with NumPy

From Loops to Arrays: Efficient Mathematical Computation

Central Question

Can we use computers to simulate the spread of infectious diseases and predict epidemic outcomes?

In March 2020, public health officials worldwide faced urgent questions: How fast will COVID-19 spread? When will hospitals be overwhelmed? What impact will social distancing have? These questions require mathematical models that track how diseases spread through populations.

The classic SIR model divides a population into three groups: - Susceptible: people who could catch the disease - Infectious: people currently infected who can spread it - Recovered: people who’ve recovered (or died) and are no longer infectious

The model uses differential equations to describe how people move between these states over time. But these equations rarely have closed-form solutions—we need numerical methods to approximate them.

Today, we’ll learn to: 1. Work with NumPy arrays, Python’s fundamental tool for numerical computing 2. Understand vectorization—expressing operations on entire arrays efficiently 3. Implement numerical integration to solve differential equations 4. Simulate an SIR epidemic and explore intervention strategies

We’ll also take a brief detour to see VSCode, a professional development environment widely used in industry. This is optional—you can continue with Spyder—but I want you to see the tools used in real-world data science.

By the end of class, you’ll be able to simulate disease outbreaks, predict their trajectories, and evaluate public health interventions—all with about 50 lines of Python code.

Exercise 1: NumPy Fundamentals

Goal: Master the basics of NumPy arrays—the foundation for all scientific computing in Python.

Python lists are flexible and convenient, but they’re inefficient for numerical work. When we need to perform millions of arithmetic operations on large datasets, we need something better.

NumPy (Numerical Python) provides: - Efficient arrays that store homogeneous data compactly in memory - Vectorized operations that work on entire arrays without explicit loops - A vast library of mathematical functions - The foundation for pandas, scipy, scikit-learn, and most scientific Python packages

Let’s start by setting up our environment and exploring what NumPy can do.

Just-in-Time Concept: NumPy Arrays

Key properties: 1. Homogeneous: All elements have the same type (unlike lists) 2. Fixed size: Once created, size doesn’t change (unlike lists that can grow) 3. Efficient: Stored contiguously in memory, enabling fast operations 4. N-dimensional: Can be 1D, 2D, 3D, or higher

Why does this matter?

When you write:

total = sum(daily_cases_list)  # Python list

Python must: 1. Loop through each element 2. Check its type 3. Call the appropriate addition operation 4. Handle potential type conversions

With NumPy:

total = daily_cases.sum()  # NumPy array

NumPy: 1. Knows all elements are the same type 2. Uses optimized C code to sum them in one pass 3. Operates directly on contiguous memory

The result? NumPy can be 10-100x faster for numerical operations.

Exercise 1.6: Linear Algebra Essentials

NumPy provides comprehensive linear algebra operations through np.linalg. Let’s explore the basics that appear frequently in scientific computing and epidemiology.

Vectors and Dot Products

import numpy as np

# Two population groups
susceptible = np.array([800, 600, 400, 200])
infectious = np.array([10, 30, 50, 70])

# Dot product: how "aligned" are two vectors?
dot_product = np.dot(susceptible, infectious)
# Equivalent: susceptible @ infectious

print(f"Dot product: {dot_product}")
Dot product: 60000

Matrix Operations

Matrices are 2D arrays. Let’s see fundamental operations:

# Contact matrix: how much do age groups interact?
# Rows/cols represent age groups: [0-20, 21-40, 41-60, 61+]
contact_matrix = np.array([
    [8, 3, 2, 1],   # Young interact mostly with young
    [3, 6, 3, 1],   # Middle age balanced
    [2, 3, 5, 2],   # Older adults
    [1, 1, 2, 4]    # Elderly interact less overall
])

# Current infected population by age group
infected = np.array([50, 30, 20, 10])

# Matrix-vector multiplication: expected new infections
# Each age group's contribution = contact rate × number infected
new_infections = contact_matrix @ infected
# Equivalent: np.matmul(contact_matrix, infected)

print(f"New infections by age group: {new_infections}")
New infections by age group: [540 400 310 160]

Matrix Multiplication

# Transmission probability matrix
transmission_prob = np.array([
    [0.05, 0.03],  # Age group 1 → 1, 1 → 2
    [0.03, 0.04]   # Age group 2 → 1, 2 → 2
])

# Contact rates
contact_rates = np.array([
    [10, 5],
    [5, 8]
])

# Combined effect: contact × transmission probability
combined_risk = transmission_prob @ contact_rates

print(f"Combined risk matrix:\n{combined_risk}")
Combined risk matrix:
[[0.65 0.49]
 [0.5  0.47]]

Matrix Inverse

Sometimes we need to solve systems of linear equations. The inverse is one approach:

# Simple 2×2 system: ax + by = e, cx + dy = f
# Matrix form: Ax = b
A = np.array([
    [2, 1],
    [1, 3]
])

b = np.array([8, 13])

# Solve using inverse: x = A⁻¹b
A_inv = np.linalg.inv(A)
solution = A_inv @ b

print(f"Matrix A:\n{A}")
print(f"Inverse of A:\n{A_inv}")
print(f"Solution: {solution}")

# Verify: A @ solution should equal b
verification = A @ solution
print(f"Verification (should equal b): {verification}")
Matrix A:
[[2 1]
 [1 3]]
Inverse of A:
[[ 0.6 -0.2]
 [-0.2  0.4]]
Solution: [2.2 3.6]
Verification (should equal b): [ 8. 13.]
NoteBetter Way to Solve Linear Systems

For solving Ax = b, use np.linalg.solve(A, b) instead of computing the inverse explicitly. It’s more accurate and faster:

solution = np.linalg.solve(A, b)

Eigenvalues and Eigenvectors

Eigenvalues are crucial for understanding system dynamics, including epidemic growth rates:

# Next-generation matrix for disease transmission
# Each element: expected infections caused in group i by group j
NGM = np.array([
    [1.5, 0.3],
    [0.3, 1.2]
])

# Find eigenvalues and eigenvectors
eigenvalues, eigenvectors = np.linalg.eig(NGM)

print(f"Eigenvalues: {eigenvalues}")
print(f"Eigenvectors:\n{eigenvectors}")

# The largest eigenvalue is the basic reproduction number R₀
R0 = np.max(eigenvalues)
print(f"\nBasic reproduction number R₀: {R0:.3f}")
print(f"Epidemic will {'grow' if R0 > 1 else 'die out'} (R₀ {'>' if R0 > 1 else '<'} 1)")
Eigenvalues: [1.6854102+0.j 1.0145898+0.j]
Eigenvectors:
[[ 0.85065081+0.j -0.52573111+0.j]
 [ 0.52573111+0.j  0.85065081+0.j]]

Basic reproduction number R₀: 1.685+0.000j
Epidemic will grow (R₀ > 1)
ImportantWhy Eigenvalues Matter in Epidemiology

The dominant eigenvalue of a disease transmission matrix is the basic reproduction number (R₀): - R₀ > 1: Disease spreads (epidemic) - R₀ < 1: Disease dies out - R₀ = 1: Endemic equilibrium

This is the mathematical foundation for “flattening the curve”!

ImportantWhy Is NumPy So Much Faster?
  1. Compiled C code: NumPy operations run in optimized C/Fortran libraries
  2. Vectorization: CPU can perform multiple operations simultaneously (SIMD - Single Instruction Multiple Data)
  3. Memory locality: Data is contiguous in memory, enabling fast access
  4. No Python overhead: No per-element type checking or function calls

For scientific computing, this performance difference is crucial. Imagine simulating a million-person epidemic over 365 days. Vectorization can mean the difference between minutes and hours!

Exercise 2.2: The SIR Model - Mathematical Background

The SIR model divides a population into three compartments:

  • S(t): Susceptible individuals (can catch the disease)
  • I(t): Infectious individuals (currently infected, can spread disease)
  • R(t): Recovered individuals (immune, cannot catch or spread disease)

The model is governed by three differential equations:

\[ \begin{align} \frac{dS}{dt} &= -\frac{\beta S I}{N} \\[10pt] \frac{dI}{dt} &= \frac{\beta S I}{N} - \gamma I \\[10pt] \frac{dR}{dt} &= \gamma I \end{align} \]

Where: - \(N = S + I + R\) is the total population (constant) - \(\beta\) is the transmission rate (contacts per day × probability of transmission per contact) - \(\gamma\) is the recovery rate (1/infectious period) - \(R_0 = \beta / \gamma\) is the basic reproduction number

Interpretation: - \(\frac{dS}{dt}\): Susceptible people become infected at rate \(\beta S I / N\) - \(\frac{dI}{dt}\): New infections minus recoveries - \(\frac{dR}{dt}\): Infected people recover at rate \(\gamma\)

Euler’s Method for Numerical Integration

We can’t solve these equations analytically, but we can approximate the solution numerically using Euler’s method:

\[ y(t + \Delta t) \approx y(t) + \frac{dy}{dt} \cdot \Delta t \]

For the SIR model:

\[ \begin{align} S(t + \Delta t) &\approx S(t) + \frac{dS}{dt} \cdot \Delta t \\ I(t + \Delta t) &\approx I(t) + \frac{dI}{dt} \cdot \Delta t \\ R(t + \Delta t) &\approx R(t) + \frac{dR}{dt} \cdot \Delta t \end{align} \]

This is a discrete-time approximation of the continuous-time dynamics.

Exercise 2.3: Vectorized SIR Simulation

The loop-based implementation works, but for more complex models (e.g., age-structured populations, spatial models), we need vectorization.

Let’s create a vectorized version that: 1. Is more concise 2. Runs faster 3. Is easier to extend

Your Turn: Vectorized Implementation

import numpy as np
import matplotlib.pyplot as plt

def sir_model_vectorized(S0, I0, R0, beta, gamma, t_max, dt):
    """
    Simulate SIR model using vectorized NumPy operations.
    
    Parameters:
    -----------
    S0, I0, R0 : float
        Initial susceptible, infectious, recovered populations
    beta : float
        Transmission rate
    gamma : float
        Recovery rate
    t_max : float
        Maximum time to simulate
    dt : float
        Time step
        
    Returns:
    --------
    t, S, I, R : numpy arrays
        Time points and population trajectories
    """
    N = S0 + I0 + R0
    n_steps = int(t_max / dt)
    
    # Initialize arrays
    S = np.zeros(n_steps)
    I = np.zeros(n_steps)
    R = np.zeros(n_steps)
    t = np.arange(n_steps) * dt
    
    # Initial conditions
    S[0], I[0], R[0] = S0, I0, R0
    
    # Euler's method - vectorized where possible
    for step in range(1, n_steps):
        # Current state
        S_curr, I_curr, R_curr = S[step-1], I[step-1], R[step-1]
        
        # Derivatives
        infection_rate = beta * S_curr * I_curr / N
        recovery_rate = gamma * I_curr
        
        dS_dt = -infection_rate
        dI_dt = infection_rate - recovery_rate
        dR_dt = recovery_rate
        
        # Update (vectorized arithmetic)
        S[step] = S_curr + dS_dt * dt
        I[step] = I_curr + dI_dt * dt
        R[step] = R_curr + dR_dt * dt
    
    return t, S, I, R

# Run simulation

    S0=990, I0=10, R0=0,

def sir_multiple_scenarios(S0, I0, R0, beta_values, gamma, t_max, dt):
    """
    Simulate SIR model for multiple beta values simultaneously.
    
    This demonstrates true vectorization: simulating many scenarios at once!
    """
    N = S0 + I0 + R0
    n_steps = int(t_max / dt)
    n_scenarios = len(beta_values)
    
    # Initialize 2D arrays: rows = scenarios, columns = time steps
    S = np.zeros((n_scenarios, n_steps))
    I = np.zeros((n_scenarios, n_steps))
    R = np.zeros((n_scenarios, n_steps))
    t = np.arange(n_steps) * dt
    
    # Initial conditions (same for all scenarios)
    S[:, 0] = S0
    I[:, 0] = I0
    R[:, 0] = R0
    
    # Convert beta_values to column vector for broadcasting
    beta = np.array(beta_values).reshape(-1, 1)
    
    # Euler's method with vectorized scenarios
    for step in range(1, n_steps):
        S_curr = S[:, step-1]
        I_curr = I[:, step-1]
        
        # Vectorized across scenarios!
        infection_rate = beta.flatten() * S_curr * I_curr / N
        recovery_rate = gamma * I_curr
        
        S[:, step] = S_curr - infection_rate * dt
        I[:, step] = I_curr + (infection_rate - recovery_rate) * dt
        R[:, step] = R[:, step-1] + recovery_rate * dt
    
    return t, S, I, R

# Simulate different transmission rates
beta_scenarios = [0.3, 0.5, 0.7]
labels = [f'β = {b}' for b in beta_scenarios]

t, S, I, R = sir_multiple_scenarios(
    S0=990, I0=10, R0=0,
    beta_values=beta_scenarios,
    gamma=0.1,
    t_max=160, dt=1
)

# Plot infectious curves for all scenarios
plt.figure(figsize=(10, 6))
for i, label in enumerate(labels):
    plt.plot(t, I[i, :], label=label, linewidth=2)

plt.xlabel('Time (days)')
plt.ylabel('Infectious individuals')
plt.title('Effect of Transmission Rate on Epidemic Dynamics')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

# Calculate R₀ for each scenario
R0_values = np.array(beta_scenarios) / 0.1

for beta, R0 in zip(beta_scenarios, R0_values):
    print(f"β = {beta}: R₀ = {R0:.1f}")
