## What you should be practicing

### Data structures

You should be able to recognize the basic purposes of:

- **list** — an ordered, mutable collection;
- **tuple** — an ordered collection that is generally used as a fixed grouping of values;
- **dictionary** — a collection of key-value pairs;
- **set** — a collection of distinct values, useful especially for membership and set operations.

The important skill is not memorizing definitions. It is learning to ask:

> **What operations do I need to perform on this information, and which data structure naturally supports those operations?**

### Control flow

You should be comfortable reading and writing:

```python
if
elif
else
```

and:

```python
for
```

loops.

You should also understand how a variable can serve as an **accumulator** whose value changes as a loop executes.

### Algorithms

For the final problems, focus on the distinction between:

```text
problem
   ↓
algorithm
   ↓
Python implementation
```

An algorithm is a precise procedure for solving a problem. Python is the language in which you express that procedure.
